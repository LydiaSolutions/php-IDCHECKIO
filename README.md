# idcheckio-php-client
PHP client for checking identity documents through the IdCheck.IO API. It submits document images or machine-readable zone (MRZ) text for analysis, retrieves task status and results, and provides administration and sandbox clients. Shared transport, configuration and request/response models support these API clients.

## Installation & Usage
### Composer

To install the bindings via [Composer](http://getcomposer.org/), add the following to `composer.json`:

```
{
  "repositories": [
    {
      "type": "git",
      "url": "https://github.com/ariadnext/php-IDCHECKIO.git"
    }
  ],
  "require": {
    "ariadnext/php-IDCHECKIO": "*@dev"
  }
}
```

This configuration selects the upstream repository, not this LydiaSolutions fork. Then run `composer install` in the consuming application.

### Manual Installation

Download the files and include `autoload.php`:

```php
    require_once('/path/to/idcheckio-php-client/autoload.php');
```

## Getting Started

Follow the [installation procedure](#installation--usage), set `IDCHECKIO_BASE_URL` to the service base URL supplied for your environment, then use the following health request. Configure HTTP Basic credentials through `Configuration::setUsername()` and `Configuration::setPassword()` for authenticated operations; obtain them through your application configuration. Image or MRZ submission sends document data to the remote service and creates an analysis task.

```php
<?php
require_once(__DIR__ . '/vendor/autoload.php');

$config = new idcheckio\Configuration();
$config->setHost(getenv('IDCHECKIO_BASE_URL'));
$api_instance = new idcheckio\api\AdministrationApi(new idcheckio\ApiClient($config));

try {
    $result = $api_instance->getHealth();
    print_r($result);
} catch (Exception $e) {
    echo 'Exception when calling AdministrationApi->getHealth: ', $e->getMessage(), PHP_EOL;
}

?>
```
